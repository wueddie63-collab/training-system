📐 佺葉工程顧問道路工程設計指南

🧠 核心工程設計指南（九大等同主題分項）

  • 🛣️ 道路線形設計
    • 1. 公路 (Highway)
      • 📘 依據：公路路線設計規範
        📌 線形特點：高速率高標準，強調長直線與大半徑圓曲線
        📊 控制指標：最大超高率 e_max = 6%~8%，嚴格檢算停止視距(SSD)與超車視距
    • 2. 市區道路 (Urban Road)
      • 📘 依據：市區道路工程設計規範
        📌 線形特點：受限路權與交叉路口，速率較低，重視橫斷面多功能配置
        📊 控制指標：標準快車道寬 3.25m ~ 3.50m，標準路拱 1.5% ~ 2.0%
    • 3. 農路 (Agricultural Road)
      • 📘 依據：農路設計標準
        📌 線形特點：地形起伏大且路幅狹窄，採低設計速率以適應地形
        📊 控制指標：容許較大之縱坡度（部分路段可達 12%~15%）與極小彎道半徑
  • 💧 排水工程
    • 1. 水理計算與洪峰流量
      • 📌 重現期設定：側溝 5年，箱涵 10~25年
        🔍 計算方法：合理化公式法 $Q=CIA/360$
    • 2. 側溝與集水設施
      • 🔍 洩水坡度：縱坡需 ≥ 0.5%，嚴禁倒坡
        📌 集水井佈設：間距控制在 20m ~ 30m
    • 3. 過路箱涵與管涵
      • 📊 水流流速：流速應控制在 0.6 m/s ~ 3.0 m/s 之間
        🔍 結構物回填：壓實度需 ≥ 90% 或採用 CLSM
  • 🛡️ 擋土工程
    • 1. 擋土牆型式選定
      • 📌 低邊坡：重力式或半重力式擋土牆（H ≤ 4m）
        🔍 高邊坡：懸臂式（H = 4~8m）或扶壁式擋土牆
    • 2. 結構穩定性計算
      • 📊 安全係數：傾覆常時 FS ≥ 2.0；滑動常時 FS ≥ 1.5
        🔍 承載力檢算：牆底最大地基反力需小於地盤容許承載力
    • 3. 牆體排水與回填
      • 📌 解壓設施：每 2~3 m² 設置一處 2"~3" 洩水孔
        🔍 回填材料：嚴禁採用高塑性粘土，需使用砂礫料
  • 🌉 橋梁工程
    • 1. 下部結構與基礎
      • 📌 基礎型式：全套管基樁、版基或沉箱基礎
        🔍 基樁規範：孔底沉渣厚度 ≤ 20 cm（摩擦樁 ≤ 5 cm）
    • 2. 上部結構幾何
      • 📊 上部鋼筋：構造物淨保護層厚度需達 7.5 cm
        📌 預力控制：鋼腱張拉力與延伸量誤差在 ± 5% 內
    • 3. 橋面附屬設施
      • 🔍 伸縮縫配置：依伸縮量選用齒狀、橡膠或鋼浪型伸縮縫
        📊 伸縮構造：兩側平整度嚴格控管，避免車輛跳車
  • ⚡ 管線工程
    • 1. 地下管線佈設幾何
      • 📌 最小埋深：快車道下直埋管線最小覆土深度 ≥ 1.2m
        🔍 垂直淨距：不同管線交會時，垂直淨距離 ≥ 15~30cm
    • 2. 管線共同管道
      • 📊 配置型式：配設電纜管路(CCBOX)或綜合管溝
        📌 人手孔蓋設計：與路面齊平，周邊高低差 ≤ ±2mm
    • 3. 管道回填與壓實
      • 🔍 專用回填料：管溝回填全面採用 CLSM
        📊 壓實基準：傳統回填每層厚度 ≤ 30cm，壓實度 ≥ 95%
  • 💡 照明工程
    • 1. 照度與均勻度規範
      • 📌 平均照度：主要道路基準值約 15 ~ 20 Lux
        🔍 均勻度指標：綜合均勻度 $U_o$ (最小/平均) ≥ 0.4
    • 2. 燈具幾何配置
      • 📊 配置型式：單側、雙側相對、雙側交錯、中央分隔島配置
        📌 燈桿間距：桿高 $H$ 與間距 $S$ 比例控制在 S = 3H ~ 4H
    • 3. 電氣安全與構造
      • 🔍 接地電阻：全線燈桿接地電阻 ≤ 10 Ω
        📊 基礎檢算：需進行風力與地震力之傾覆穩定計算
  • 🏗️ 土方工程
    • 1. 土方挖填平衡設計
      • 📌 體積修正：考量挖、填方之土壤變化率（$L$ 與 $C$ 值）
        🔍 計算方法：採用平均斷面法 (Average End Area Method)
    • 2. 路基填築與壓實度
      • 🔍 分層壓實：分層灑水滾壓，每層鬆散厚度 ≤ 30cm
        📊 技術指標：路床頂面以下30cm內壓實度 ≥ 95%
    • 3. 土質改良與整地
      • 📌 軟弱地盤：換土法、穩定劑改良(水泥/石灰)或加勁格網
        🔍 邊坡坡度：填方邊坡 ≤ 1:1.5；挖方邊坡依土質調整
  • 🚶 人行道工程
    • 1. 無障礙幾何線形
      • 📌 橫斷坡度：標準橫坡 ≤ 1.0%（最大不得超過 2.0%）
        🔍 縱斷坡度：原則依道路縱坡，≥ 5% 時需設扶手平台
    • 2. 緣石斜坡與無障礙通路
      • 📊 斜坡道坡度：無障礙緣石斜坡坡度需 ≤ 1:12
        📌 通行淨寬：人行道最小無障礙通行淨寬度 ≥ 1.5m
    • 3. 鋪面構造與導盲設施
      • 🔍 高壓透水磚：符合透水基準，基層級配壓實度 ≥ 90%
        📊 警示帶設計：路口設置定位構磚（點狀）與導向構磚（條狀）
  • 🌿 植栽工程
    • 1. 植栽帶與植生地幾何
      • 📌 喬木植栽帶：淨寬度建議 ≥ 1.5m，確保根系發育空間
        🔍 客土深度：喬木層 ≥ 100~120cm；灌木層 ≥ 45~60cm
    • 2. 行車視距與淨空安全
      • 📊 視距三角區：路口交會處灌木高度需 ≤ 50cm，避免阻擋視線
        📌 垂直淨空：樹冠修剪維護需符合道路通視淨空高度 ≥ 4.6m
    • 3. 結構防護與排水
      • 🔍 防根設施：鄰路面側加設阻根板，避免根系破壞鋪面結構
        📊 植生穴排水：穴底具良好滲透性，必要時配置盲溝導水
